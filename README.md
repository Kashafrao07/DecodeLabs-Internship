 DecodeLabs AI Chatbot - Week 1 Project

 About The Project
This is a Rule-Based AI Chatbot developed in Python for DecodeLabs International Internship Program - Week 1.
The chatbot can interact with users, provide information, and perform basic tasks using Object-Oriented Programming.

 Key Features
- Personalized Greeting with User Name
- Show Current Time and Date
- Tell Random Jokes, Quotes, and Facts
- Built-in Calculator for Basic Math
- About Section with Bot Information
- Help Menu for All Commands

Technologies Used
- Python 3
- Object Oriented Programming
- datetime and random Libraries
- VS Code
